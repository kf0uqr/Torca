Icom Radio Control Script - v 0.0.1a

Python script using Rigplane and Pyside6 to create a gui to control the Icom 7300, 9700, and 705. Will also provide current solar conditions, satellite tracking, and many other features to come.

To start run from command line in folder containing all files:

python main.py

You may need to install missing dependancies such as rigplane, pyside6:

pip install (missing package name)
